# 使用指南

Solaris 管理你提供的代理订阅和 mihomo 配置，不提供代理账户或节点。

## 安装

从 [GitHub Releases](https://github.com/Ember-Moth/Solaris/releases) 下载适合系统的安装包：

| 系统 | 安装包 |
| --- | --- |
| macOS 26 及以上，Apple Silicon / Intel x64 | `Solaris-<版本>-macos-universal.dmg` |
| Windows 10 / 11，x64 | `Solaris-<版本>-windows-x64-setup.exe` |
| Windows 11，ARM64 | `Solaris-<版本>-windows-arm64-setup.exe` |

macOS：打开 DMG，将 Solaris 拖入「应用程序」。首次连接时按提示允许网络扩展并添加 VPN 配置。

Windows：运行安装程序并允许管理员授权。日常使用无需以管理员身份打开 Solaris。当前 Windows 安装包未签名，
请核对下载来源；发布附件中的 `SHA256SUMS` 可用于核对文件。

## 第一次连接

1. 在「订阅」中导入订阅链接或本地 YAML 配置。
2. 选择分流方式：使用订阅自带的规则，或把节点加入「我的方案」。
3. 在「代理」中选择节点，可先进行 HTTP 测速。
4. 返回「概览」并连接。Windows 可在设置中选择 TUN、系统代理或同时启用；macOS 使用系统 VPN 接管流量。

macOS 未连接时，部分导入内容会显示「连接后读取」；连接时会完成读取和校验。
配置错误时，按提示修正后重试。Naive、AnyTLS + REALITY 和 Snell 的示例见 [配置指南](mihomo-fork.md)。

## 分流与节点

| 模式 | 行为 |
| --- | --- |
| 规则 | 按当前配置或方案的规则选择出口 |
| 全局 | 使用全局策略组选择的出口 |
| 直连 | 直接访问目标 |

「订阅自带」使用所选订阅的策略组与规则；「我的方案」可以汇集多个订阅的节点，按地区组织节点，添加策略组和
服务、域名、IP 段规则。可以先运行规则测试，再结合「连接」页确认实际出口。

HTTP 测速检查请求是否成功；TCP 测速只检查端口连接，不能证明协议认证或 UDP 可用。

## 链式出口与组网

在「分流」中配置 WARP 或 VPN Gate 链式出口，选择经由节点，再用规则把指定流量交给该出口。
WARP 需要注册账户，VPN Gate 依赖其志愿者服务器。添加出口本身不会把所有流量切换过去。

也可以添加 Tailscale、ZeroTier 或 EasyTier 网络，完成对应的登录或授权后，为需要访问的设备添加域名或 IP 段规则。
换机后需要重新完成设备授权或填写密钥。

## 关闭窗口、退出与断开

关闭窗口默认把 Solaris 留在托盘（macOS 上是菜单栏），连接继续运行。在「设置」里可以把关闭窗口改为「退出 Solaris」。

从托盘或菜单栏选「退出 Solaris」、在 macOS 上按 ⌘Q 或在 Dock 中退出，都会先断开连接，再退出应用。退出后不会自动重连，
包括睡眠唤醒之后；下次打开 Solaris 后手动连接。断开失败时会询问重试还是仍然退出；仍然退出时，隧道可能仍在运行。

需要界面运行的自动任务会在退出后暂停，例如订阅和 GEO 数据更新。下次打开时会检查需要处理的更新。

## 备份与恢复

在「设置 → 备份与同步」中导出备份。恢复时可选择替换现有内容或合并，并先查看恢复预览。

- iCloud 仅在 macOS 的签名安装版中可用，需要系统已登录 Apple 账户。
- Google Drive 是否可用以安装包中是否显示该入口为准；可用时通过浏览器登录。
- 云备份保存快照，需要恢复时主动选择一份快照。
- 备份不加密，可能含订阅令牌和配置原文。请妥善保管，勿附在公开问题报告中。
- 应用单独保存的 WARP 账户、组网密钥和 Google 登录令牌不包含在备份中；换机后可能需要重新登录或填写。

完整的数据范围见 [隐私说明](../PRIVACY.md)。

## 更新与卸载

在「设置 → 关于」检查更新。下载安装包并完成校验后，由你确认安装。
Windows 升级沿用已有安装位置；Windows on ARM 使用 ARM64 安装包。

Windows 从「设置 → 应用」卸载，默认保留订阅、设置和日志，也可选择清除。
macOS 卸载前先在 Solaris 设置中停用系统扩展，再删除应用。

## 常见问题

| 现象 | 处理方式 |
| --- | --- |
| macOS 无法连接，提示需要授权 | 按应用提示到系统设置允许网络扩展，确认 VPN 配置，再重试 |
| Windows 提示后台服务不可用 | 使用对应架构的完整安装包重新安装；保留安装器显示的错误，勿仅替换某个 DLL |
| 升级提示文件占用或架构不一致 | 关闭正在使用 Solaris 文件的程序后重试；仍失败时提交错误信息，不手动混用不同架构的文件 |
| TCP 测速成功，但网页打不开 | 再做 HTTP 测速，检查模式、策略组、规则和节点认证信息 |
| 导入后仍使用旧节点 | 确认正在使用该订阅的规则，或已将它加入「我的方案」节点池 |
| 退出后网络仍经代理 | 退出时断开失败并选了仍然退出，或界面意外关闭。重新打开 Solaris，使用「断开」停止连接 |
| 没有 Google Drive 入口 | 该安装包未提供此功能；可使用本地备份，macOS 还可使用 iCloud |

Tor 出口暂未实现。链式出口和组网功能还需要对应服务或网络的账户、授权与可用连接。

## 反馈问题

在 [GitHub Issues](https://github.com/Ember-Moth/Solaris/issues) 中说明系统与架构、Solaris 版本、操作步骤、预期结果
和实际错误。可从「设置 → 关于」导出诊断信息；分享前检查其中的域名、节点名和错误内容。
原始崩溃报告单独导出，不会自动上传。

源码构建、架构和维护流程见 [开发文档](development.md)。
